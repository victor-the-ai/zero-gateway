Multi-Key Swapping

        

          Provide comma-separated API keys for Google Gemini or other providers. If one key runs out of quota, it auto-swaps to the second key immediately.
        

      


      
      

        

          
        

        
Reset Window Tracking

        

          Parses Retry-After headers and Gemini retryDelay error payloads to put keys on cooldown until their reset window expires.
        

      


      
      

        

          
        

        
OpenAI-Compatible Proxy

        

          Drop-in endpoint at http://localhost:8080/v1. Supports streaming (SSE) and full tool/function calling formats.
        

      


      
      

        

          
        

        
Zero-Auth & BYOK

        

          Start immediately without signing up using zero-auth endpoints (Pollinations), or supply your own free keys for Groq, Cerebras, and Gemini.
        

      


      
      

        

          
        

        
Configurable Swapping

        

          Both intra-provider key swapping and inter-provider cascading are configurable options. Toggle via environment variables, code, or per-request headers.
        

      


      
      

        

          
        

        
Git-Synced Registry

        

          Community curated YAML definitions with daily canary probing. Deprecated models and paid walls are detected and pruned automatically.

# 1. Install via pip
pip install zerogateway

# 2. Run with smart fallback
from zerogateway import ZeroGatewayClient

client = ZeroGatewayClient(enable_key_rotation=True)

response = client.chat.completions.create(
    model="llama-3.3-70b", # or "gemini-flash", "openai", "auto"
    messages=[{"role": "user", "content": "Explain async in Python in 1 line."}]
)

print(response.choices[0].message.content)
print(f"Served by: {response.provider_id}")


        


        
        


// 1. Install via npm or load directly in HTML (<script src="zerogateway.browser.global.js"></script>)
npm install zerogateway

// 2. Run in Node.js or directly in browser with multi-key rotation
import { ZeroGatewayClient } from "zerogateway";

const client = new ZeroGatewayClient({
  enableKeyRotation: true,
  enableProviderRotation: true,
});

const response = await client.chat.completions.create({
  model: "llama-3.3-70b", // or "openai", "gemini-2.0-flash", "auto"
  messages: [{ role: "user", content: "Explain async in TypeScript in 1 line." }]
});

console.log(response.choices[0].message.content);
console.log(`Served by: ${response._zerogateway_meta.provider_name}`);

        KNOWLEDGE BASE & FAQ
      

      
Frequently Asked Questions

      

        Everything you need to know about rate limits, key swapping, free AI providers, and local proxy setup.
      

    


    

      
      

        
        

          Zerogateway is an open-source, OpenAI-compatible AI gateway and client router (available for Python, TypeScript/JavaScript, and direct in-browser usage). It aggregates 8 free-tier LLM providers behind a unified interface. When any provider returns an HTTP 429 (Too Many Requests) rate limit, Zerogateway automatically swaps to another active API key or seamlessly cascades to an alternate provider hosting the same model family without failing your application.
        

      


      
      

        
        

          If you have multiple free API keys from Google AI Studio (Gemini), Groq, or Cerebras, you can provide them as comma-separated values in your environment (e.g. GEMINI_API_KEY="key1,key2,key3") or client options. When key 1 hits a quota limit, Zerogateway records the exact reset window from provider error headers, puts key 1 on temporary cooldown, and transparently routes all subsequent requests to key 2.
        

      


      
      

        
        

          Instead of using arbitrary sleep delays, Zerogateway intelligently parses standard HTTP Retry-After headers, rate limit reset epoch timestamps (x-ratelimit-reset), and provider-specific error payloads (such as Google Gemini's details.retryDelay). Rate-limited keys and providers remain throttled only until their quota window resets, returning to the active pool automatically.

Running zerogateway serve --port 8080 launches a proxy at http://localhost:8080/v1 that supports streaming (Server-Sent Events) and tool calling. Configure Cursor or Cline with Base URL http://localhost:8080/v1, API Key zerogateway, and model auto or llama-3.3-70b.
