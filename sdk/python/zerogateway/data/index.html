Engineered for Free Tier Resilience

Everything you need to run on free AI

Multi-Key Swapping

Provide comma-separated API keys for Google Gemini or other providers. If one key runs out of quota, it auto-swaps to the second key immediately.

Reset Window Tracking

Parses Retry-After headers and Gemini retryDelay error payloads to put keys on cooldown until their reset window expires.

OpenAI-Compatible Proxy

Drop-in endpoint at http://localhost:8080/v1. Supports streaming (SSE) and full tool/function calling formats.

Zero-Auth & BYOK

Start immediately without signing up using zero-auth endpoints (Pollinations), or supply your own free keys for Groq, Cerebras, and Gemini.

Configurable Swapping

Both intra-provider key swapping and inter-provider cascading are configurable options. Toggle via environment variables, code, or per-request headers.

Git-Synced Registry

Community curated YAML definitions with daily canary probing. Deprecated models and paid walls are detected and pruned automatically.

Usage Modes

Two Minutes to Zero-Cost AI

# 1. Install
pip install zerogateway

# 2. Run with smart fallback
from zerogateway import ZeroGatewayClient

client = ZeroGatewayClient(enable_key_rotation=True)

response = client.chat.completions.create(
    model="llama-3.3-70b", # or "gemini-flash", "fast-smart", "auto"
    messages=[{"role": "user", "content": "Explain async in Python in 1 line."}]
)

print(response.choices[0].message.content)
print(f"Served by: {response.provider_id}")

# Launch the local OpenAI-compatible server
zerogateway serve --port 8080

# Configure your IDE (Cursor, Cline, Continue.dev, LibreChat):
Base URL: http://localhost:8080/v1
API Key:  zerogateway
Model:    auto (or gemini-flash, llama-3.3-70b, gpt-4o-mini)

# If Groq hits 429, the proxy cascades seamlessly in the background!

curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer zerogateway" \
  -H "X-Enable-Key-Rotation: true" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "What is the speed of light?"}]
  }'

# In your .env file:
# Provide multiple comma-separated keys for Google AI Studio or Groq:
GEMINI_API_KEY="AIzaSyKey1...,AIzaSyKey2...,AIzaSyKey3..."
ENABLE_KEY_ROTATION=true
ENABLE_PROVIDER_ROTATION=true

# When Key 1 hits 429, Zerogateway records the exact reset window from
# Google's retryDelay payload, puts Key 1 on cooldown, and uses Key 2!
